# 🍀 로또 6/45 스마트 정밀 분석기 (Lotto Analyzer)

대한민국 동행복권 로또 6/45의 **1회부터 최신 회차까지 전수 데이터**를 기반으로 한 정밀 통계 분석, 동일 회차 매칭, 스마트 번호 추천, **최대 50개 조합 일괄 백테스팅 시뮬레이터** 프로그램입니다.

외부 라이브러리(`pip install`) 설치 없이 **Python 기본 내장 기능만으로 100% 즉시 구동**되며, 웹 브라우저 기반의 모던 대시보드와 콘솔 CLI를 모두 지원합니다.

---

## 🌟 주요 핵심 기능

### 1. 🎯 동일 회차 매칭 분석 (2개, 3개, 4개, 5개 일치) ★신규
- **기준 회차 선택 및 전수 매칭**:
  - 최신 회차 또는 원하는 회차를 선택하면, 역대 모든 회차 중 당첨 번호가 **5개 / 4개 / 3개 / 2개 동일했던 회차**들을 정확히 분류하여 표출
  - **직관적인 시각화**: 일치한 번호는 **선명한 3D 컬러 공(✓ 매칭 뱃지)**으로 강조되고, 불일치한 번호는 **어두운 딤드(dimmed)** 처리되어 어떤 번호가 일치했는지 한눈에 즉시 파악
  - 일치 등급별(5개 일치, 4개 일치, 3개 일치, 2개 일치) 원클릭 필터 탭
- **역대 5개 동일 데칼코마니 회차 쌍 (총 21쌍) 특별 전시**:
  - 1회부터 최신 회차까지 6개 중 5개 번호가 똑같이 출현했던 기적의 21개 회차 쌍(예: 제 4회 vs 제 258회 등) 목록 및 번호 비교 뷰 제공

### 2. 🚀 최대 50개 번호조합 일괄 백테스팅 시뮬레이터 ★신규
- **대규모 50개 조합 지원**:
  - 최대 50개의 번호 조합을 한 번에 등록하여 역대 전 회차(1,245회) 매주 구매 시의 통합 손익을 백테스팅
- **간편한 3가지 입력 모드**:
  1. **텍스트 일괄 붙여넣기**: 여러 줄(최대 50줄)로 복사한 번호를 한 번에 붙여넣으면 자동 파싱
  2. **원클릭 빠른 채우기**: `+ 랜덤 5개`, `+ 랜덤 10개`, `+ 랜덤 50개 꽉 채우기`, `+ 추천 번호 가져오기`
  3. **직접 입력 및 개별 관리**: 6자리 직접 입력, 등록된 조합 칩(Chips) 목록에서 [✕] 개별 삭제
- **정밀 시뮬레이션 결과 대시보드**:
  - **4대 종합 요약**: 총 투자비용 (예: 50개 조합 × 1,245회 = 62,250,000원), 총 획득 당첨금, 순손익, 통합 수익률(ROI %)
  - **전체 등수별 당첨 건수**: 1등, 2등, 3등, 4등, 5등 총합
  - **조합별 성적 랭킹 테이블 (1위~50위)**: 어떤 번호 조합이 가장 많은 당첨금을 탔는지 순위별 정렬
  - **1~3등 고액 당첨 히스토리 리스트**: 몇 번 조합이 몇 회차에 몇 등 당첨되었는지 상세 내역

### 3. 📊 정밀 통계 분석 대시보드
- **번호별 출현 빈도 순위 (1~45번)**: 역대 출현 횟수 인터랙티브 막대 차트 (전체 / 최근 100회 / 최근 50회)
- **최다 출현 (Hot Numbers) vs 최소 출현 (Cold Numbers)**: 1위 34번(187회 출현), 13번(184회) 등 랭킹
- **장기 미출현 번호 주기 분석 (Cold Ranking)**: 최근 5회, 10회, 15회 이상 연속 미출현 번호 추적
- **홀짝 비율 분석**: 역대 당첨 번호의 홀수:짝수 비율 (3:3, 4:2, 2:4가 전체의 약 80% 차지) 도넛 차트
- **구간대(색상)별 분포**: 1~10(노랑), 11~20(파랑), 21~30(빨강), 31~40(회색), 41~45(초록)
- **총합(Sum) 분포 히스토그램**: 100~175 범위(전체의 70% 이상) 집중도
- **연속 번호(연번) & AC값(산술 복잡도) 분석**

### 4. 🪄 스마트 번호 추천 & 조합기
- **5대 추천 전략**: 황금 통계 밸런스(강력 추천), 최다 빈도 가중치(Hot), 미출현 반등(Cold), 최근 트렌드, 자동 무작위
- **커스텀 필터**: 1~45 인터랙티브 번호판에서 고정수(★ 최대 5개) 및 제외수(X) 클릭 지정
- **로또 용지(SLIP) 스타일 카드 출력** 및 **원클릭 클립보드 복사**, **시뮬레이터로 번호 전송** 지원

### 5. 📜 역대 회차 전수 검색 & 초고속 동기화
- 1회부터 최신 회차까지 모든 당첨 결과, 보너스 번호, 1등 당첨 인원, 1인당 당첨금 검색
- GitHub CDN + 동행복권 API Fallback 듀얼 엔진으로 전 회차 데이터 10여 초 만에 동기화 완료
